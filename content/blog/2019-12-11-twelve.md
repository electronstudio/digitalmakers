# Games

In addition to Minecraft, we will play two other games that I used to play when I was a teenager!  [Xonotic](https://xonotic.org/) and  [BZFlag](http://www.bzflag.org).  They are both free and they both run fine on Chromebooks.

* Please a mouse if you have one!
* Please bring headphones if you have them!

If you want to save time by installing Xonotic and BZFlag before Wednesday, the instructions are below, depending on which operating system you are using....

## GalliumOS Linux

First we will install the Snap Store. This is similar to the App Grid Software Centre you already have but it has more up to date software available. (The same software as the software centre on Ubuntu Linux in fact).

Open terminal window and type:

    sudo apt update

(type your password, press enter)

    sudo apt install snapd

(press enter twice)

    sudo snap install snapstore

(press enter twice)

Reboot.

Click on the start menu and type: snap

Click on the snap store icon to launch the store. Now follow the instructions for Ubuntu below except use the snap store instead of the software centre.

## Ubuntu Linux  (and GalliumOS with the Snap Store)

Click on Ubuntu Software Centre (icon looks like an A), click on the search icon (magnifying glass), type bzflag into the search box, click on the first result that comes up, click install.

Click on the search icon, type xonotic into the search box, click on the first result that comes up, click install.  Wait for it to download.

The games will now be availble to run on your start menu or launcher but might not be listed under 'games' so you will have to type the name to find them.

## Windows

Go to [http://www.bzflag.org](http://www.bzflag.org) and click Windows to download the installer. Run the installer by double clicking on it. Follow the prompts.  You can now find the game on your start menu.

(Note the windows version seems to have a bug - Start Server doesn’t work in the game. If you want to run your own server you have to use the separate server program you find in the windows start menu. And you will need to enter your own IP address in the game to connect to it. )

Go to [https://xonotic.org/](https://xonotic.org/) and click the red download button or the link that says 'download as zip'.  Unzip the folder from inside the zip file somewhere you can find it, e.g. drag it to your desktop.  To play, double click xonotic.exe in the Xonotic folder.

## Mac

Go to  [http://www.bzflag.org](http://www.bzflag.org) and click macOS to download the zip file. Unzip the zip file (double click on it) to create the game app: bzflag-2.4.18.app. Drag the app into your Applications folder. You can now launch by double clicking bzflag-2.4.18.app

Go to [https://xonotic.org/](https://xonotic.org/) and click the red download button or the link that says 'download as zip'.  Unzip the zip file (double click on it) to get a folder called Xonotic.  Drag this folder into your applications folder.

Open a Terminal window and type:

    xattr -r -d com.apple.quarantine /Applications/Xonotic/Xonotic.app/

You can now launch Xonotic by double clicking the Xonotic.app
